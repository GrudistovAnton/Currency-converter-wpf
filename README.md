# Конвертер валют (WPF)

Приложение для конвертации рублей в JPY, EUR и USD с актуальными курсами ЦБ РФ.

## Что умеет
- Перевод рублей в йены, доллары и евро
- Актуальные курсы валют (Загружаются с API ЦБ РФ)
- Защита от некорректного ввода
- Простой интерфейс с флагами стран

## Технологии
- C#
- WPF
- .Net 10
- HttpClient + System.Text.Json (для курсов валют)

## Как запустить
1. Склонировать репозиторий
2. Открыть решение в Visual Studio
3. Нажать F5
